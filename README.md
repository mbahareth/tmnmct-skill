# TMNMCT — The Mega Negotiator Mega Converters Tool

Elite persuasion and negotiation skill for AI agents. Combines Chris Voss Tactical Empathy, behavioral economics, leverage architecture, NLP, and Cialdini principles into a strict Smart Selection Engine that produces high-conversion, ethical outcomes.

## What It Does

When activated, the skill forces a precise three-part response:

1. **Target Analysis & Leverage Map** — Diagnose the counterpart across vulnerability, decision structure, emotional state, power balance, and more.
2. **Chosen Tool(s) & Why** — Select and justify the highest-leverage combination of frameworks for this specific situation.
3. **Actionable Execution** — Deliver copy-paste ready scripts, labeling phrases, calibrated questions, and handling for resistance.

It prioritizes voluntary, high-value agreements and long-term relationship strength over short-term extraction.

## How to Use

### For Grok / Compatible Agents
1. Place the skill folder in your skills directory (e.g. `~/.grok/server-skills/tmnmct/` or equivalent).
2. The agent will automatically trigger on requests involving sales, negotiation, persuasion, objection handling, or deal closing.
3. Example triggers:
   - "Help me close this deal and handle the price objection"
   - "How do I negotiate better terms with a stronger counterparty?"
   - "Write a persuasive pitch for skeptical investors"

### Manual Use
Read `SKILL.md` for the mandatory workflow. Load reference files as needed:
- `references/tactical-empathy.md` — Full Voss toolkit (mirroring, labeling, accusation audit, calibrated questions, etc.)
- `references/frameworks.md` — Behavioral economics, cognitive reprogramming, Cialdini, NLP
- `references/leverage-architecture.md` — Diagnosis protocol and matching rules

### Key Features
- **Decision Guide** table for fast tool selection
- Precise Voss execution rules and sequences
- Cultural notes for Middle East / Saudi contexts
- Strict ethical constraints (no coercion or deception)
- Progressive disclosure: lean core + detailed references

## Ethical Use

This skill is designed for ethical influence only. It explicitly forbids coercion, threats, deception, or any tactic that removes free choice. Tactical Empathy is used to create genuine understanding, not as a manipulative trick.
